## 📋 Project Overview

ShopEase is a full-stack e-commerce web application built with the MERN stack (MongoDB, Express.js, React, Node.js). It provides a complete online store solution with admin product management, customer browsing, shopping cart, order placement, and email notifications.

## ✨ Features

### Admin Panel
- 🔐 Secure JWT authentication
- 📊 Dashboard with statistics (products, categories, orders, revenue)
- 📦 Product management (add, edit, delete with multiple images)
- 📋 Order management (view all orders, update status)

### Customer Storefront
- 🏠 Home page with featured products
- 🔍 Product search, filtering (category, price), sorting
- 📱 Grid/List view toggle and pagination
- 🖼️ Product detail with image carousel
- 🛒 Shopping cart with localStorage
- 📝 Order placement with shipping details
- 📧 Email notifications (product info, order confirmation)
- 📞 Contact page

### Technical Highlights
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ RESTful API architecture
- ✅ Secure file uploads with Multer
- ✅ Transactional emails with Nodemailer
